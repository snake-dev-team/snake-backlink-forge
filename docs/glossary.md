# Snake Backlink Forge — Glossary

> Copied from MASTER_PROMPT.md Appendix A. Sorted alphabetically.

| Term | Meaning |
|---|---|
| **ADR** | Architecture Decision Record |
| **Anchor** | Text displayed for a hyperlink |
| **Backlink** | Link from another site pointing to the user's money site |
| **BYOK** | Bring Your Own Key — user supplies their own 2captcha/CapSolver API key |
| **Campaign** | Group of backlink-build jobs targeting one money site |
| **Credit** | 1 successful backlink placement consumes 1 credit |
| **CRX** | Chrome Extension binary package format |
| **Drip feed** | Building links at low, steady frequency to avoid unnatural spikes |
| **Ethical Mode** | Default safeguard profile: Premium pool only + 10/day limit |
| **HWID** | Hardware ID (not used in this design — no device binding) |
| **Money site** | The site the user wants to boost in search engine rankings |
| **MV3** | Chrome Manifest V3 extension platform |
| **NSIS** | Nullsoft Scriptable Install System — Windows installer framework |
| **Pool** | Credit tier: Premium (DR 40+) or Standard (DR 0-39) |
| **SePay** | Vietnamese payment webhook service matching bank transfers to orders |
| **Target** | External site where a backlink will be placed (blog, forum, web 2.0, directory) |
